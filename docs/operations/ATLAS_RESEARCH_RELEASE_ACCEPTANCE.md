## Stage reporting

BUILT means code exists on a named review head. TESTED means named commands/runs executed on that exact tree. MERGED requires an approved merge SHA. DEPLOYED requires the actual Streamlit source SHA. LIVE VERIFIED requires authenticated, functional and visually inspected production evidence for the specific gate. Generated fixture screenshots never satisfy live verification. Production-before/fixture-after comparisons are useful review material but are not actual production-before/production-after acceptance.

## Source and methodology boundaries

- The digest consumes the existing customer projection; it never changes Action, Fair Value, Opportunity, Confidence, signal times, financial calculations or publication eligibility.
- Dated price, snapshot source and independently retained context remain distinct. Missing news, company facts, analyst targets, financial periods, earnings/transcripts and price history remain explicitly unavailable.
- News summaries quote only already-admitted company news with publisher/time. They do not infer new business events from price movement. Analyst targets/consensus require the existing commercial-display gate.
- Mockup financial figures, curves, signals, news and consensus never become production evidence. Native orbital decoration and the bounded component organization are new interpretations, not asserted pixel parity.
- Public Report Card stays OFF. No production writes, licensed calls, paid AI, source-host mutations, protected migration, infrastructure changes or automatic activation are authorized by UI approval.
