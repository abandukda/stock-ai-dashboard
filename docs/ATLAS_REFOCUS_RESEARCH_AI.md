## Concrete candidate behavior

`build_reasoning_packet` takes only an already customer-admitted page. It carries original identity/evidence IDs, retains the close date, and does not copy the close date into an unknown valuation date. It does not read a source, acquire data, write a cache, certify a snapshot, recompute ratings or change publication authority.

Known-answer example uses **synthetic** close100 and Fair Value120: the educational arithmetic is `(120 / 100 - 1) * 100 = +20%`, explicitly not expected return or probability. An inconsistent pre-existing header gap is not consumed by this calculation. Model assumptions are surfaced only from the existing `CERTIFIED_ATLAS_VALUATION` projection; absent assumptions produce an honest limitation instead of an invented thesis.

The customer sees a responsive “How to interpret the evidence” section distinguishing observed price, model estimate, arithmetic and valuation limits. It states that a favorable gap alone does not establish quality/catalyst/position size, and that strong earnings do not guarantee share-price appreciation. It leaves deteriorating-margin and price/earnings-divergence source statements unchanged.
